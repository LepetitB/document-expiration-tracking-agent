# 01 — Rationale: ทำไมต้องแก้ปัญหานี้

> **ประโยคเดียว:** บริษัทขนส่งต้องต่อ ภาษีรถ · พ.ร.บ. · ประกันภัย ของรถทุกคันทุกปี ถ้าลืมแม้ฉบับเดียว **รถวิ่งไม่ได้ ถูกปรับ หรือเกิดอุบัติเหตุแล้วเคลมไม่ได้** แต่ SME ส่วนใหญ่ยังติดตามด้วย Excel ที่ต้องพิมพ์และเปิดดูเอง

---

## 1. บริบท: เอกสารรถที่ต้องต่อทุกปี

บริษัทสมมติ *สยามฟลีท ทรานสปอร์ต* (SME ขนส่งสินค้า) มีรถบรรทุก **40 คัน**

| เอกสารต่อคัน | ต่ออายุ | รวม 40 คัน |
|-------------|--------|-----------|
| ภาษีรถประจำปี | ทุกปี | 40 ครั้ง/ปี |
| พ.ร.บ. (ประกันภาคบังคับ) | ทุกปี | 40 ครั้ง/ปี |
| ประกันภัยรถ (ภาคสมัครใจ) | ทุกปี | 40 ครั้ง/ปี |
| **รวม** | | **120 ครั้ง/ปี ≈ สัปดาห์ละ 2–3 ครั้ง** |

รถแต่ละคันซื้อมาไม่พร้อมกัน วันหมดอายุจึง **กระจายไปทั้งปี** ไม่มีช่วงไหนให้ "ต่อทีเดียวทั้งหมด"

แต่ละเอกสาร **มาจากคนละที่และหน้าตาไม่เหมือนกัน**:
- ป้ายภาษีจากกรมการขนส่งทางบก
- พ.ร.บ. และประกันจากบริษัทประกันหลายเจ้า บางฉบับเป็นภาษาอังกฤษ
- รูปแบบวันที่ต่างกัน เช่น `26/11/69`, `๑ ธ.ค. ๒๕๖๙`, `4 Dec 2026`

## 2. Pain Point จากหน้างาน

### กระบวนการปัจจุบัน (As-Is)
```
ต่อ พ.ร.บ./ประกัน/ภาษี เสร็จ → ได้เอกสาร (กระดาษ / PDF ทางอีเมล / รูปทาง LINE)
   → ธุรการพิมพ์ทะเบียนรถ + วันหมดอายุลง Excel เอง
   → เก็บเอกสารไว้ในแฟ้มหรือ Drive
   → ต้องจำเองว่าควรเปิด Excel มาดูเมื่อไร
   → รู้ตัวเมื่อ... ตำรวจเรียกตรวจ / ไปต่อภาษีแล้วต่อไม่ได้ / เกิดอุบัติเหตุแล้วเคลมไม่ได้
```

### สาเหตุที่ทำให้พลาด (Root causes)
| # | สาเหตุ | ตัวอย่าง |
|---|-------|---------|
| 1 | **ข้อมูลติดอยู่ในรูปหรือกระดาษ** | กรมธรรม์ พ.ร.บ. ส่งมาเป็นรูปใน LINE แต่ไม่มีใครพิมพ์ลง Excel |
| 2 | **พิมพ์ผิด โดยเฉพาะ พ.ศ. ↔ ค.ศ.** | พิมพ์ "2570" ลงช่องที่ Excel ตีความเป็น ค.ศ. ระบบเลยคิดว่าเหลืออีก 500 ปี |
| 3 | **หลายวันที่ในเอกสารเดียว** | ป้ายภาษีมีทั้งวันจดทะเบียนและวันครบกำหนด กรมธรรม์มีทั้งวันออกและวันเริ่ม/สิ้นสุดคุ้มครอง |
| 4 | **ไม่มีการเตือนล่วงหน้า** | Excel ไม่เตือนเอง ต้องมีคนเปิดดู |
| 5 | **ความรู้อยู่กับคนคนเดียว** | ธุรการลา ไม่มีใครรู้ว่ารถคันไหนใกล้หมด |
| 6 | **ตอบคำถามง่าย ๆ ไม่ได้ทันที** | ผู้จัดการถามว่า "พรุ่งนี้รถคันไหนออกวิ่งได้บ้าง" ต้องไล่ดูทีละแถว |

## 3. ถ้าไม่ทำ จะเกิดผลเสียอะไร

### 3.1 ผลทางกฎหมายและการเงิน (จากแหล่งข้อมูลสาธารณะ)

| เอกสารที่หมด | ผลที่ตามมา | อ้างอิง |
|-------------|-----------|--------|
| **พ.ร.บ.** | ปรับสูงสุด **10,000 บาท**, ต่อภาษีรถไม่ได้, เกิดอุบัติเหตุไม่ได้รับความคุ้มครองตาม พ.ร.บ. | [Autospinn](https://www.autospinn.com/2023/06/compulsory-insurance-130962), [Thai PBS](https://www.thaipbs.or.th/news/content/337472) |
| พ.ร.บ. (เมื่อเกิดอุบัติเหตุ) | กองทุนทดแทนผู้ประสบภัยจ่ายผู้บาดเจ็บก่อน แล้ว **เรียกเงินคืนจากเจ้าของรถพร้อมเงินเพิ่ม 20%** | [Autospinn](https://www.autospinn.com/2025/01/third-party-liability-insurance-140947) |
| **ภาษีรถ** | เงินเพิ่ม **1% ต่อเดือน**, ขาดเกิน 1 ปีต้องตรวจสภาพก่อนต่อ, ขาดต่อเนื่อง 3 ปี **ทะเบียนถูกระงับ** | [Sanook](https://www.sanook.com/auto/96219/), [แนวหน้า](https://www.naewna.com/n/?p=91771) |
| **ประกันภัยรถ (ภาคสมัครใจ)** | เกิดอุบัติเหตุ **บริษัทต้องจ่ายค่าซ่อมรถตัวเอง + ค่าเสียหายคู่กรณีเอง** (รถบรรทุกชนแต่ละครั้งอาจหลักแสนถึงหลักล้านบาท) | — |
| ทุกเอกสาร | รถต้องจอดจนกว่าจะต่อเสร็จ ทำให้ **ส่งของไม่ได้ เสียรายได้และความเชื่อมั่นจากลูกค้า** | — |

> ⚠️ ตัวเลขค่าปรับมาจากสื่อ ควรตรวจกับเว็บไซต์ทางการ (กรมการขนส่งทางบก, คปภ.) ก่อนใช้ในวิดีโอ

### 3.2 สถานการณ์ตัวอย่าง (Insurance claim)

**"เคลมไม่ได้ เพราะ พ.ร.บ. ขาดไป 3 วัน"**
1. รถบรรทุก 71-0099 ชนรถจักรยานยนต์ มีผู้บาดเจ็บ
2. ตรวจพบว่า **พ.ร.บ. หมดอายุไปแล้ว 3 วัน** และ **ประกันภาคสมัครใจจะหมดในอีก 3 วัน** เพราะธุรการลาพักร้อน และไม่มีใครเปิดดู Excel
3. ผลที่ตามมา:
   - บริษัทต้องรับผิดชอบค่ารักษาผู้บาดเจ็บเอง
   - กองทุนทดแทนเรียกเงินคืนพร้อมเงินเพิ่ม 20%
   - โดนปรับสูงสุด 10,000 บาท
   - รถถูกจอด งานส่งของล่าช้า

> สถานการณ์นี้มีอยู่ในข้อมูลตัวอย่างของแอปจริง (รถ 71-0099) ใช้เดโมได้ทันที ระบบจะขึ้นสถานะ **⛔ ห้ามออกวิ่ง**

**ต้นทุนแฝงทุกวัน (สมมติฐาน ต้องยืนยันด้วยการสัมภาษณ์):**
- พิมพ์ข้อมูลฉบับละ ~5 นาที × 120 ฉบับ = 10 ชั่วโมง/ปี
- เปิดตรวจ Excel สัปดาห์ละ ~30 นาที = 26 ชั่วโมง/ปี
- รวม **~36 ชั่วโมงต่อปี** ที่ระบบทำแทนได้ และยังลดความเสี่ยงที่ประเมินค่าไม่ได้

## 4. ทำไมต้องเป็น Document Intelligence
1. **ต้นเหตุอยู่ที่ข้อมูลติดในเอกสาร:** ถ้าทำแค่ระบบเตือนแต่ยังต้องพิมพ์เอง ก็พลาดที่ขั้นแรกเหมือนเดิม
2. **เอกสารมาจากหลายบริษัทประกัน หน้าตาไม่เหมือนกัน:** OCR แบบ template ต้องทำแม่แบบทีละเจ้า
3. **Vision AI ปัจจุบันอ่านเอกสารไทยได้โดยไม่ต้องเทรน:** แยกวันจดทะเบียน/วันเริ่ม/วันสิ้นสุดได้ และส่งออกเป็นข้อมูลที่มีโครงสร้าง
4. **ค่าปรับครั้งเดียวสูงกว่าค่า AI ทั้งปีหลายเท่า:** อ่านเอกสาร 120 ฉบับต่อปีมีค่าใช้จ่ายระดับหลักสิบถึงหลักร้อยบาท

## 5. การยืนยันปัญหา (Validation plan)
- [ ] สัมภาษณ์ธุรการของบริษัทขนส่ง / โรงงานที่มีรถ 1–2 ราย
- [ ] ขอดูตัวอย่าง Excel ติดตามเอกสารรถจริง (ปิดข้อมูลส่วนตัว)

**แบบสอบถาม 5 ข้อ**
1. บริษัทมีรถกี่คัน ติดตามวันหมดอายุภาษี/พ.ร.บ./ประกันด้วยวิธีไหน?
2. ใช้เวลาต่อสัปดาห์เท่าไรกับงานนี้?
3. เคยมีเอกสารรถหมดอายุโดยไม่รู้ตัวไหม? เกิดอะไรขึ้น?
4. เอกสารได้มาในรูปแบบไหน (กระดาษ / PDF / รูปใน LINE)?
5. ถ้ามีระบบถ่ายรูปเอกสารแล้วเตือนอัตโนมัติ จะใช้ไหม? กังวลอะไร?
